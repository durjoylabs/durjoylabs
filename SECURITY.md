# 🔒 Security Policy

Thank you for helping keep Durjoy Labs secure.

We take the security of our projects seriously and appreciate responsible disclosure of security vulnerabilities.

---

# 📌 Supported Versions

| Version | Supported |
|----------|-----------|
| Latest Release | ✅ Yes |
| Development Branch | ✅ Yes |
| Older Versions | ❌ No |

---

# 🛡 Reporting a Vulnerability

If you discover a security vulnerability, please do **not** create a public GitHub issue.

Instead, report it privately with the following information:

- Project name
- A detailed description of the issue
- Steps to reproduce
- Potential impact
- Screenshots (if applicable)
- Proof of Concept (optional)

---

# 📧 Contact

For responsible disclosure, please contact us through our official communication channels.

Public security contact information will be added when available.

---

# ⏱ Response Timeline

We aim to:

- Acknowledge reports within **3 business days**
- Investigate the issue as quickly as possible
- Provide updates during the investigation
- Release a fix when appropriate

---

# ✅ Responsible Disclosure

We kindly ask that you:

- Do not publicly disclose the vulnerability before a fix is available.
- Give us reasonable time to investigate and resolve the issue.
- Avoid accessing, modifying, or deleting user data.

---

# 🚫 Out of Scope

The following are generally not considered security vulnerabilities:

- Typographical errors
- Documentation improvements
- UI design suggestions
- Feature requests
- Low-impact issues without security implications

---

# ❤️ Thank You

Your efforts help make Durjoy Labs projects safer for everyone.

We appreciate your responsible disclosure and support.
